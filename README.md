# Calculator-2.0 🧮

A simple graphical calculator built with C++ and Windows Forms.

## 🚀 Release: Transition to GUI (Windows Forms)

**Main Change:** Full switch from a command-line interface (CLI) to a graphical user interface (GUI).

> ⚠️ **Important:** The current build is a preview version for interface testing. The business logic is temporarily disabled.

### 🆕 What's New:
* **Interface:** Visual framework and button layouts created.
* **Refactoring:** Code completely rewritten to handle GUI events.
* **Architecture:** Layouts and menus prepared for future features.
